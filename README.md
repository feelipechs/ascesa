# Ascesa

Associação dedicada ao resgate, cuidado e adoção responsável de animais em situação de vulnerabilidade.

Site institucional construído com **Next.js 16**, **PostgreSQL + Prisma 7**, **shadcn/ui**, **Tailwind CSS 4**, **TanStack Query v5**, **Zod 4**, **NextAuth 5** e **Framer Motion**.

## Projeto

- `frontend/` — Aplicação Next.js (App Router)
- `plano-refatoracao/` — Plano de refatoração completo

Ver `frontend/AGENTS.md` para contexto técnico detalhado.
